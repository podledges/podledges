# Profile asset generation

`README.md` embeds `assets/podle-reactor.svg` and `assets/waveform.svg` as images. Both files are generated by `scripts/waveform.py` from GitHub commit data. They must not be hand-edited.

## Data source and freshness

The generator lists every owned, non-fork repository through `GET /user/repos`, then reads commits attributed to `podledges` from each repository's default branch. Dates and streak boundaries use the profile owner's Singapore time zone, UTC+08:00. Override `PROFILE_UTC_OFFSET_HOURS` if the profile time zone changes. Private repository names are always rendered as `<PRIVATE🔒>`.

The `profile-assets` workflow runs every eight hours and updates both SVGs together. It requires a repository secret named `WAVEFORM_TOKEN` with metadata and contents read access to every owned repository. The normal Actions token can read only this repository, so the workflow deliberately fails rather than replace accurate all-repository statistics with incomplete public-only data.

When repositories are added, make sure the token can read them. Rotate the secret before its expiry.

## Rendering compatibility

GitHub embeds repository SVG files as images. The assets use only SVG elements accepted in that path, including SMIL `<animate>` and `<animateTransform>`. They do not use scripts, event handlers, `foreignObject`, or README-level CSS. This is the same README-compatible mechanism used by dynamic SVG profile generators such as GitSkins.

Glow filters use explicit user-space regions, and outer strokes are inset from each viewBox edge to prevent clipping. Waveform signals, week guides, ticks, and the axis all share the chart bounds `x=170..838`.

## Validation

Run the deterministic regression suite:

```sh
python3 -m unittest discover -s tests -v
```

Render live data locally with an appropriate token:

```sh
GH_TOKEN=... python3 scripts/waveform.py
```

The generated SVG root and accessible description include the calculation date. The highlighted label is computed from the busiest exact seven-day window in the current eight-week capture.
